Create an archive with fsspec, then list and read its members.

The example creates its own data. It writes `example-fsspec.zstar` in your current
directory; running it again replaces that archive.

## Set up

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), save the
complete example below as `tutorial_fsspec.py`, and run:

```sh
uv run tutorial_fsspec.py
```

The script declares Python 3.11 or later and its dependencies with PEP 723
metadata. uv installs them automatically.

## Create the archive

`fo` names the archive; filesystem paths name its members. Write text with
`open()` or bytes with `pipe_file()`. Parent directories are created automatically.
Close each member before writing the next; the outer `with` block finalizes the
archive. Append and update modes are unsupported.

<Example source={source} lang="python" region="create" />

## List and read members

Reopen in read mode. `ls(..., detail=False)` returns names; `cat_file()` returns
bytes. Open a member in text mode to decode UTF-8.

<Example source={source} lang="python" region="read" />

## Open a member by URL

`fsspec.core.url_to_fs()` resolves `zstar://<member>::<archive>` to a filesystem
and member path. Close both with a `with` block. Keep the filesystem open across
related reads to reuse metadata.

<Example source={source} lang="python" region="url" />

You should see:

```text
['docs/hello.txt']
Hello from Zstar
Read through a chained URL
```
