Create an archive with fsspec's filesystem interface, then list and read its
members. Use this interface for standard filesystem operations such as opening
files, listing directories, and reading bytes.

The example creates its own data. It writes `example-fsspec.zstar` in your current
directory; running it again replaces that archive.

## Set up

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), save the
complete example below as `tutorial_fsspec.py`, and run:

```sh
uv run tutorial_fsspec.py
```

The script declares Python 3.11 or later and its dependencies with PEP 723
metadata. uv installs them automatically. `zstar-py` includes fsspec and registers
the `zstar` protocol, so no separate fsspec installation is needed.

## Create the archive

Open a `zstar` filesystem with `mode="w"`. `fo` names the output archive;
paths passed to filesystem methods name members inside it.

Use `fs.open(..., "wt", encoding="utf-8")` to write text, or `pipe_file()` to
add bytes. Parent directories are created automatically. Close each member
before writing the next one. Leaving the outer `with` block finalizes the
archive. Append and update modes are unsupported.

## List and read members

Reopen the filesystem in its default read mode. `ls()` lists a directory;
`detail=False` returns names. Open a member in text mode to decode UTF-8, or
use `cat_file()` to read its bytes.

<Example source={source} lang="python" region="read" />

## Open a member by URL

Resolve a chained URL `zstar://<member>::<archive>` with
`fsspec.core.url_to_fs()` to get a filesystem and member path. The `with` block
closes both the member and the filesystem. Binary mode returns bytes, and
`read(5)` selects the first five bytes. Keep a filesystem open as above when
reading multiple members to reuse the archive's metadata.

<Example source={source} lang="python" region="url" />

You should see:

```text
['docs/hello.txt']
Hello from Zstar
Read through a chained URL
```
