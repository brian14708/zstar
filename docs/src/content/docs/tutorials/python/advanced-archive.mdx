Use `ArchiveWriter` and `Archive` to create, read, and verify an archive.
For filesystem operations, start with the
[fsspec tutorial](/zstar/tutorials/python/first-archive/).

The example generates `example.txt` inside `example.zstar` in your current
directory. Running it again replaces the archive.

## Set up

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then save
the complete example below as `tutorial_file.py` and run:

```sh
uv run tutorial_file.py
```

The script declares Python 3.11 or later and its dependencies with PEP 723
metadata. uv installs them in an isolated environment automatically.

`verify()` checks the entire archive for errors, including content you have
not read. Call it inside the `with` block, before the reader closes.
