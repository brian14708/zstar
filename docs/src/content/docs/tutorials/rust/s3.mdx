upload it to S3, read a file and byte range, then delete the uploaded object.

## Set up

You need an existing S3 bucket with versioning disabled and credentials that
allow uploading, reading, and deleting objects whose keys start with
`zstar-tutorial/`. Use a bucket intended for testing.

Set your bucket, region, and credentials:

```sh
export ZSTAR_S3_BUCKET=your-test-bucket
export AWS_REGION=us-east-1
export AWS_ACCESS_KEY_ID=your-access-key
export AWS_SECRET_ACCESS_KEY=your-secret-key
# Set AWS_SESSION_TOKEN too when using temporary credentials.
```

For an S3-compatible service, set `ZSTAR_S3_ENDPOINT`, for example
`http://127.0.0.1:9000` for local RustFS.

Use the project from the [local-file tutorial](/zstar/tutorials/rust/first-archive/).
Replace its `Cargo.toml` dependency section to enable the `s3` feature:

```toml
[dependencies]
zstar = { version = "0", features = ["s3"] }
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }
```

Replace `src/main.rs` with the complete example below and run `cargo run`.
The example uses the S3 and object-store types re-exported by Zstar.

## Configure access

The example reads environment variables and passes credentials explicitly to
`AmazonS3Builder`. The builder does not discover environment credentials,
profiles, or instance roles on its own. `AWS_SESSION_TOKEN` is optional.
