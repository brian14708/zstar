Create `example.zstar` containing `example.txt`, read the file and a byte range. Running the example again replaces the archive.

## Set up

Create a Rust project:

```sh
cargo new zstar-tutorial
cd zstar-tutorial
```

Replace the empty `[dependencies]` section in `Cargo.toml` with:

```toml
[dependencies]
zstar = { version = "0", features = ["fs"] }
tokio = { version = "1", features = ["macros", "rt-multi-thread", "fs"] }
```

Replace `src/main.rs` with the complete example below and run `cargo run`.

## Write the archive

`append_bytes()` adds a member. `finish()` writes the index and footer;
drop the returned file handle before reopening the archive.

## Read a file and a byte range

Open the archive with `AsyncLocalFileSource`. `read()` returns the whole member;
`read_range()` uses a half-open range, so `0..5` returns `Hello`.

<Example source={source} lang="rust" region="read" />

You should see:

```text
Hello from Zstar
Hello
```
