Create the archive from the [local-file tutorial](/zstar/tutorials/go/first-archive/),
upload it to S3, read a file and byte range, then delete the uploaded object.

## Set up

You need an existing S3 bucket with versioning disabled and credentials that
allow uploading, reading, and deleting objects whose keys start with
`zstar-tutorial/`. Use a bucket intended for testing.

Set your bucket, region, and credentials:

```sh
export ZSTAR_S3_BUCKET=your-test-bucket
export AWS_REGION=us-east-1
export AWS_ACCESS_KEY_ID=your-access-key
export AWS_SECRET_ACCESS_KEY=your-secret-key
# Set AWS_SESSION_TOKEN too when using temporary credentials.
```

For an S3-compatible service, set `ZSTAR_S3_ENDPOINT`, for example
`http://127.0.0.1:9000` for local RustFS.

Use the module from the [local-file tutorial](/zstar/tutorials/go/first-archive/)
and add the S3 adapter:

```sh
go get github.com/brian14708/zstar/go/s3
```

Replace `main.go` with the complete example below, then run `go mod tidy` and
`go run .`. The AWS SDK uploads and deletes objects; Zstar's S3 adapter provides
range reads.
