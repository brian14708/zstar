Create `example.zstar` containing `example.txt`, read the file and a byte range. Running the example again replaces the archive.

## Set up

Create a Go module and add the SDK:

```sh
mkdir zstar-tutorial
cd zstar-tutorial
go mod init example.com/zstar-tutorial
go get github.com/brian14708/zstar/go
```

Save the complete example below as `main.go`, then run `go run .`.

## Write the archive

`Header` describes the member; `Add()` writes its bytes. Close the writer to
finalize the archive. Deferred calls release resources on error.

## Read a file and a byte range

`ReaderAtSource` adapts the file for range reads. `Read()` takes an offset
and byte count; offset 0 and length 5 return `Hello`.

